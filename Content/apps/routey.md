Routey was an offline-first iPhone app for organizing a rural route. It kept a master list of stops in order, searched it locally, and used on-device text recognition to add a stop from a photo of a label, so it kept working without a cell signal.

> Routey was discontinued in October 2026. It was never released on the App Store. The source code stays on GitHub as an archived project.

## Where it ended

Routey reached internal TestFlight builds on iPhone and was not developed further. The archived repository keeps the code and history.

Routey was an independent project, not affiliated with, endorsed by, or sponsored by any postal or delivery service. Apple is a trademark of Apple Inc.
